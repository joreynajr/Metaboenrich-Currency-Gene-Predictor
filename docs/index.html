How it works

Code maps of the two scoring engines: which module does what, in what order.

Pipeline Map

updated for D20hand-written
Synopsis
A step-by-step code map of the default run (python -m metaboenrich): load Human-GEM, decide currency metabolites, map the DAA table, build the metabolite–reaction graph, solve Kirchhoff current flow, score, write outputs. Each step names its module, functions and library calls, and the page covers the other entry points (network export, atlases, benchmark, blind predictions).
Dataset
Human-GEM 2.0.1, pruned to the locked network of 3,958 metabolites, 6,377 reactions and 16,356 edges; any user DAA table. No data is embedded.
Method
Current flow (grounded sparse LU per component), currency rules, scoring, pathway test.
Built
Written by hand from commit 48786d1; updated 2026-10-16 for the orientation change (D20).

Random Walk Pipeline

updated for D20hand-written
Synopsis
The same map for the experimental --mode walk, which replaces current flow with a directed, non-backtracking absorbing random walk: state space, absorption, reach probability, successful traffic and folding back to scores, with a state-space diagram and a walk-versus-current-flow comparison. Its benchmark summary shows the walk does better than current flow with increased sources and much worse with decreased sources, the default since D20.
Dataset
Locked Human-GEM network (21,787 walk states); inborn-error benchmark summary (20 disorders, 160 patients, rank among 2,302 genes) from runs on 2026-10-16 and 2026-10-01.
Method
Absorbing random walk conditioned on absorption (Doob h-transform), compared with current flow.
Built
Written by hand from commit 0f6c135; updated 2026-10-16 with that day's benchmark numbers.

Metaboenrich Prototype Report

orientation-independent2026-09-29
Synopsis
Progress report on the first working prototype: how the network was built and pruned, the inborn-error benchmark (raw scoring, leave-one-out and a neighbour baseline, per-disorder ranks), what changed in version 0.2, the sealed blind predictions on the lab's 12 published datasets, and the open decisions.
Dataset
Human-GEM network v0.1.1; benchmark plasma metabolomics from Miller et al. 2015 and Thistlethwaite et al. 2022 (20 disorders as groups, 160 patients, rank among 2,302 genes); blind units from predictions/published_v1.
Method
Current flow only, so its numbers hold under either orientation.
Built
29 September 2026 by tools/report/build_report.py; one sentence edited on 2026-10-16 for D20 (it can't be rebuilt locally: lab inputs missing).

Absorbing Walk Report

updated for D20generated
Synopsis
Benchmarks the absorbing walk against current flow and a neighbour baseline: how high each ranks the known causal gene, per disorder and per patient, with recall curves and a partial-absorption (κ) test. With decreased sources the walk does worse than current flow overall (group median 284 against 88.5); its orientation section shows the walk with increased sources at a median of 48.
Dataset
Plasma metabolomics from patients with a confirmed inborn error (Thistlethwaite et al. 2020, Miller et al. 2015): 20 primary disorders, 159 patients, 1 secondary case; network of 3,958 metabolites and 2,302 genes.
Method
Absorbing walk (full and partial absorption) vs current flow vs neighbour baseline.
Built
2026-10-16, commit 7b4d0ce, by tools/report/build_rw_report.py from the benchmark runs of that day.

Network Explorer

updated for D20generated · 3.9 MB
Synopsis
An interactive Cytoscape viewer of where current flow and the absorbing walk send traffic through Human-GEM for each of the 21 benchmark disorders. Switch between the current-carrying subnetwork, pathway views and the causal gene's neighbourhood, compare the two methods side by side, and see the causal gene's rank under each.
Dataset
21 group-level inborn-error cases (14 from Thistlethwaite et al. 2020, 7 from Miller et al. 2015) on Human-GEM 2.0.1; group mean z-scores only, no patient-level data.
Method
Current flow and absorbing walk, sources = decreased.
Built
2026-10-16 by tools/report/build_network_report.py; its ranks match the benchmark (42 of 42).

Testing Data

updated for D20generated

Data description; counts of increased and decreased metabolites per disorder.
Built

Human-GEM Pruning Atlas

orientation-independent4.0 MB
Synopsis
How each pruning step (inorganics, cofactors, pools, reaction edits) changes the network, without any data: per stage, each node's degree against its structural current and the pocket of metabolites it alone cuts off, with trend charts, zoomable diagrams and search. Shows that pruning removes hubs but creates islands and single-reaction bottlenecks (for example SCLY and vitamin B6).
Dataset
Human-GEM 2.0.1 at six stages, from raw (4,035 metabolites, 7,080 reactions, 38,766 edges) to the analysis network (3,958 / 6,377 / 16,356), plus a cofactors-removed-everywhere alternative.
Method
Structural current with random source–target pairs.
Built
Last changed 2026-10-06 (commit 6c27895) by tools/atlas/build_atlas.py.

Carbon Channel Atlas

superseded by D186.1 MB
Synopsis
A network built from carbon-atom links instead of hand-made currency lists: Rule 1 keeps substrate–product links that share carbon, Rule 2 removes cofactor couples. Six networks are compared on structure and on the benchmark, with an accuracy check of the carbon links against KEGG. The 3-rule pruning atlas replaced this method as the publication candidate.
Dataset
Human-GEM 2.0.1 with KEGG RCLASS pairs and RXNMapper atom maps (KEGG-checked on 2,019 reactions); 20-disorder inborn-error benchmark.
Method
Structural current and current-flow benchmark.
Built
Last changed 2026-10-06 (commit 6c27895) by tools/atlas/build_carbon_atlas.py.

3-Rule Pruning Atlas

orientation-independent6.8 MB
Synopsis
The 3-rule pruning of the carbon method: drop pools and carbon-carrying transporters, cut carrier-to-loaded links (CoA, carnitine, glutathione, cholesterol), and keep each emptied reaction's rarest link. Nine networks with structure charts, diagrams, the benchmark and the 216 rescued reactions. Rule 3 ends the CoA short circuit (median 130 to 112.5) but still trails the first method (88).
Dataset
Human-GEM 2.0.1, 9 network variants (final 3,808 metabolites, 7,676 reaction links); group-level benchmark of 20 disorders with the lab's name lookup (2026-10-02).
Method
Structural current and current-flow benchmark.
Built
2026-10-06 (commit 6c27895) by tools/atlas/build_three_rule_atlas.py.

Walk Traffic to Gene Scores

updated for D20live page
Synopsis
The network right after the absorbing walk, with edges and reactions weighted by the traffic of successful walkers, and a step-by-step account of how that traffic becomes conductivity, bottleneck, final_score and a gene's best_score. Includes route tracing from a source to its targets and back, subgraph focus and exclude, and several layouts.
Dataset
Adam et al. 2013, FH knockout vs control mouse kidney (blind unit 001): 94 mapped metabolites; on the network, 39 decreased sources and 33 increased targets.
Method
Absorbing walk, sources = decreased; compared with the published current-flow genes.
Built
2026-10-16.

MSUD Orientation Comparison

both orientationslive page
Synopsis
One dataset run with --sources decreased and --sources increased, each with the walk and with current flow, drawn as two panels of the same graph and layout with each run's roles and traffic overlaid. The walk ranks the causal gene 1 with increased sources and 888 with decreased sources; current flow ranks it 33 either way.
Dataset
Maple syrup urine disease, 18 patients, group level (Thistlethwaite et al. 2020); causal enzyme BCKDH (BCKDHA, BCKDHB, DBT).
Method
Absorbing walk and current flow under both orientations.
