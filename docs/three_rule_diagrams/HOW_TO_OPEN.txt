Metaboenrich 3-rule pruning diagrams (Human-GEM v2.0.1)

Files
  1_raw.cyjs                       Raw Human-GEM (compartments merged)
  2_carbon_method.cyjs             Carbon method (Rules 1 + 2)
  3_carbon_cleaned.cyjs            Pools and transporters dropped
  4_carbon_carriers.cyjs           Carriers removed (Rule 3: CoA, carnitine, glutathione, cholesterol)
  5_three_rule.cyjs                3-rule pruning (final)
  alt_rules12_keep_rarest.cyjs     Alternative: Rules 1-2 with the keep-rarest safeguard
  alt_acyl_merged.cyjs             Alternative: long acyl-CoAs merged (on network 3)
  alt_acyl_merged_keep_rarest.cyjs Alternative: long acyl-CoAs merged, keep-rarest safeguard
  alt_first_method.cyjs            Reference: the first method (Pruning Atlas stage 5)
  metaboenrich_pruning_style.xml   Visual style for all of the above

A reaction split into carbon links appears as its links, side by side where
the whole reaction sits in the other diagrams. All files share one layout.

Open in Cytoscape (3.10)
  1. File > Import > Network from File...  pick one .cyjs file (repeat for others).
  2. File > Import > Styles from File...   pick metaboenrich_pruning_style.xml.
  3. Style panel: choose "Metaboenrich pruning" for each network.
  4. Do not run a layout; positions are stored in the files.

Reading the diagrams
  Fill      pocket size: grey = 0, light to dark blue = 1, 2-4, 5-19, 20+
  Size      structural current (share of current carried with no data)
  Shape     circle = metabolite, square = reaction or carbon link
  Border    thick dark = cuts off a pocket; dashed = inside a pocket; dotted = island
  Faint     removed in this network
