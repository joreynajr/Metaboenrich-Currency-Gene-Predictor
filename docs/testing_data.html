1. Inborn-error benchmark (answer known). Untargeted plasma metabolomics from patients with a confirmed single-enzyme defect, as per-sample z-scores against reference plasma. The question is where the method ranks the known causal gene among the 2,302 genes on the network. These data were used to choose settings (raw scoring, decision D9) and to compare methods (current flow vs the absorbing walk, D17).

2. Blind published datasets (answer withheld). Metabolite tables the lab collected from published papers, split into analysis units. Predictions were made and committed before anyone opened the answer key (each paper's conclusions and the "Expected tool prediction" sheet; decision D14). This page uses only the data description in predictions/published_v1/units.tsv. It shows no prediction results and reads no answer key.

Possible patient overlap

Several papers in both collections come from the same clinical metabolomics programme, so some patients may appear in both. Nothing here proves an overlap; it should be checked before blind results are scored.

  • The Thistlethwaite data include an alaimo cohort of 185 samples (ALAIMO-…). The benchmark does not use it, but the blind set's Alaimo 2020 patients may be the same people.
  • Urea-cycle disorders. Burrage 2019 groups (subjects): Arginase deficiency (ARG1D): 13; Argininosuccinate lyase deficiency (ASLD): 11; Citrullinemia type 1 (ASS1D): 7; Ornithine transcarbamylase deficiency (OTCD): 17. Benchmark cohorts (patients): Ornithine transcarbamylase deficiency: 34; Citrullinemia type I: 9; Argininosuccinic aciduria: 13; Argininemia: 17.
  • GABA-transaminase deficiency appears in the benchmark (7 patients) and in Kennedy 2019.
  • Miller 2015's heparin cohorts are also in Thistlethwaite; the benchmark takes each disorder from one dataset only, so no patient is counted twice within the benchmark.
