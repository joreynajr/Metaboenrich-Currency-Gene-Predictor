What each step of the analysis does, which module and function does it, and which package does the work underneath. Every function and package call named here was checked against the code at commit 48786d1.

OverviewPackages by stepMain run, step by step Other entry pointsDependencies

In one paragraph. The main run (python -m metaboenrich) loads Human-GEM, removes currency metabolites, maps the DAA table onto model metabolites, and builds a metabolite–reaction graph. It then treats increased metabolites as current sources and decreased ones as sinks and solves Kirchhoff's equations for every source–target pair, then ranks reactions, genes and pathways by the current they carry. The heavy maths is three calls: scipy.sparse to build the Laplacian, scipy.sparse.linalg.splu to factor it once per connected component, and numpy matrix products for the per-pair currents. Everything else is pandas tables and the Python standard library. Model parsing uses no SBML library, only xml.etree.

Main run, step by step

Entry point: metaboenrich/__main__.py → main(). It parses arguments with argparse, then calls the steps below in order. A full run on Human-GEM takes a few seconds.

1

Load the model

metaboenrich/gem.py

Reads Human-GEM v2.0.1 (SBML level 3 with the FBC v2 package) into plain dataclasses. It keeps only what the analysis needs: metabolites with their HMDB/KEGG/ChEBI cross-references and formulas, reactions with participants, direction (from the flux bounds) and genes, and the gene symbol table. If the file is missing, the pinned release is downloaded and checked against its SHA-256 hash, so every machine uses the same model.

Functions
  • download_human_gem(path)Fetches the SBML and rejects it if the hash differs.
  • load_sbml(path) → ModelBuilds Species, Reaction and gene maps; forward = ub > 0, backward = lb < 0.
  • load_subsystems(path)Pathway (subsystem) per reaction from the matching YAML. Used in step 6; parsed line by line, without a YAML library.
Packages
  • xml.etree.ElementTreeParses the SBML. No libSBML or COBRApy.
  • urllib.request · hashlibDownload and hash check.
  • dataclassesModel, Species, Reaction.
Indata/Human-GEM.xml, data/Human-GEM.ymlOutModel object in memory
2

Decide what counts as currency

metaboenrich/network.py

Currency metabolites such as H⁺ (4,540 reactions) and H₂O (3,496) would connect almost everything in one step, so current would bypass real pathways. Inorganics and generic carriers are removed from every reaction. Cofactors (ATP, NAD(P)H, CoA, SAM, …) are removed only where they exchange with a partner form of themselves, and kept in their own synthesis and breakdown. Reactions that feed lumped pools are marked for dropping. The rules are only decided here; step 4 applies them.

Functions
  • resolve_currency(model, mode="role") → CurrencyRulesLooks up the curated lists (INORGANIC_CURRENCY, CARRIER_CURRENCY, POOL_METABOLITES, COFACTOR_FAMILIES) by name.
  • CurrencyRules.classify(subs, prods)Pairs cofactors across the reaction, closest formula first. A paired cofactor is an exchanger and gets removed.
  • CurrencyRules.in_family(fam, met)Recognises loaded carriers (UDP-glucose, acetyl-CoA) from the name plus the formula.
  • parse_formula(formula)Counts heavy atoms, e.g. 'C21H32N7O16P3S'.
  • load_reaction_edits(path, model)Reads reaction_edits.tsv, currently one edit (SCLY, B6 vitamers).
Packages
  • reFormula parsing and loaded-carrier name tokens.
  • collections.CounterAtom counts for formula comparison.
InModel, reaction_edits.tsv, --currency* optionsOutCurrencyRules (removed, family_of, pools, edits)
3

Load and map the DAA table

metaboenrich/daa.py

Reads the differential-abundance table and matches each row to a Human-GEM metabolite. It tries each --id-col in order, then the optional synonym table, then an unambiguous loose-name match. When several rows hit the same metabolite, the most significant row is kept. Significant metabolites with log2FC > 0 become sources and those with log2FC < 0 become targets; φ = |log2FC| is recorded.

Functions
  • load_daa(path, model, id_cols, fc_col, p_col, alpha, …)Returns the mapped table, the unmapped rows and the duplicates.
  • build_lookup(model) · map_identifier(raw, lookup)Human-GEM id, HMDB (zero-padded), KEGG, ChEBI or exact name.
  • load_name_bridge(path)The lab's id_translation.csv: synonym → KEGG/HMDB.
  • loose_key(name) · build_loose_index(model)Strips stereo prefixes and unifies acid/salt forms; accepts only keys that match exactly one metabolite.
Packages
  • pandasread_csv, column mapping, drop_duplicates("met_id").
  • numpynp.where assigns source / target roles; np.log2 for --fc-linear.
  • reIdentifier and name normalisation.
InDAA .csv/.tsv, optional id_translation.csvOutdaa table with met_id, role, phi → daa_mapping.tsv, daa_unmapped.tsv
4

Build the metabolite–reaction graph

metaboenrich/network.py

One node per metabolite (compartments merged) and one per reaction, joined by unit-conductance edges. This is where the step 2 rules take effect. Dropped: the biomass objective, blocked reactions, pool reactions, reactions with more than 20 metabolites, and reactions left with fewer than 2 metabolites (transport, exchange). The result is the locked network: 3,958 metabolites, 6,377 reactions and 16,356 edges. With --atom-pairs, each reaction is split into carbon-sharing substrate→product channels instead.

Functions
  • build_graph(model, rules, max_reaction_size=20, atom_pairs=None) → GraphBuilds nodes, undirected edges, directed arcs, reaction genes and the currency audit.
  • _usable_reactions(…)Applies every drop rule and the cofactor classification, reaction by reaction.
  • Graph.incidence()Signed edge×node matrix B; the Laplacian is L = BᵀB.
  • Graph.components() · Graph.reachable_from(v)Connected components, and directed reachability for --mode directed.
  • metabolite_degrees() · transport_genes()Feed currency_metabolites.tsv and the transporter list (step 6).
Packages
  • scipy.sparsecsr_matrix for the incidence and adjacency matrices.
  • scipy.sparse.csgraphconnected_components.
  • numpyEdge and arc arrays (int64), the is_reaction mask.
  • collections.dequeBreadth-first search over arcs.
InModel, CurrencyRules, optional atom_pairs.jsonOutGraph; currency_metabolites.tsv, currency_edges.tsv
5

Solve the current flow

metaboenrich/flow.py

For every source–target pair (s, t), inject one unit of current at s, withdraw it at t, and solve Kirchhoff's equations. It never forms a pseudoinverse. Instead it grounds one node per connected component, LU-factorises that component's Laplacian once, and solves for a unit injection at each source and target. By linearity every pair's potentials are a difference of two of those solutions, so |S| + |T| solves cover all |S| × |T| pairs.

L yv = ev (grounded, one LU per component)  →  xst = ys − yt  →  I = B xst (Ohm)  →  throughput = ½ |B|ᵀ |I|
Functions
  • current_flow(graph, sources, targets, weights, directed, tau, ground) → FlowResultProcesses pairs in chunks of 128 and accumulates conductivity, bottleneck, edge currents and endpoint effective conductance (1/Reff).
  • select_pairs(…)Drops pairs in different components, or with no directed path in directed mode → excluded_pairs.tsv. Directed mode is only this filter: the pairs that survive are solved on the same undirected Laplacian, so current can still run against a reaction's direction. Protocol §2.3 (directed current) is not implemented.
  • _potentials(graph, L, labels, nodes)The grounded LU solves.
  • _leave_one_out(…)The lowest score after dropping any single source or target (*_loo columns).
  • One-sided mode (GROUND)If only one direction is significant, current is exchanged evenly with the measured, unchanged metabolites.
Packages
  • scipy.sparse.linalg.spluThe sparse LU factorisation. This is the core numerical step.
  • numpySparse–dense products for currents and throughput; np.add.at / np.maximum.at for per-metabolite sums and maxima; np.sort for leave-one-out bottlenecks.
InGraph, source/target node lists, optional φ weightsOutFlowResult (per-node and per-edge arrays)
6

Score and rank

metaboenrich/scoring.py

Turns the per-node arrays into ranked tables. A reaction's final score is the mean percentile rank of conductivity and bottleneck: raw scores by default, leave-one-out scores with --scoring loo. Genes inherit the best score among their reactions. Pathways are tested for over-representation among the top 100 reactions. Transporters are scored separately by what they carry, because transport reactions aren't in the graph.

Functions
  • node_table(graph, flow)One row per node with every score.
  • reaction_table(…) · rank_score(df, cols)Final score; flags only_reaction_of for endpoints with a single reaction.
  • gene_table(rxn, graph, model)Best reaction score per gene. GPR and/or logic is ignored.
  • pathway_table(rxn, graph, subsystems, top_n=100)Hypergeometric test with Benjamini–Hochberg correction across subsystems.
  • transporter_table(transport, met_scores, model)Each transporter gets the score of its best carried metabolite.
Packages
  • pandasSeries.rank(pct=True) for the final score; the tables themselves.
  • scipy.stats.hypergeom.sf for pathway p-values.
  • numpyBH q-values via np.minimum.accumulate; np.bincount for node degree.
InFlowResult, Graph, subsystemsOutreactions, genes, pathways, transporters, intermediate & source/target tables

Write outputs

metaboenrich/__main__.py · metaboenrich/cytoscape.py

Writes every table as TSV and two Cytoscape GraphML files: the full network, and the subnetwork of edges that carry at least 10% of some pair's current. It also writes summary.json with run parameters, counts and a SHA-256 fingerprint of the edge list. That fingerprint matches network/network_info.json when the run used the locked network.

Functions
  • write_cytoscape(out, graph, …)Assembles node and edge attributes and applies the --cytoscape-min-current mask.
  • write_graphml(path, graph, node_attrs, edge_attrs, …)A small hand-written GraphML writer that infers each attribute's type.
Packages
  • pandasto_csv(sep="\t") for every table.
  • xml.sax.saxutils · json · hashlibXML escaping (no networkx), summary.json, edge fingerprint.
  • numpyNode and edge masks for the subnetwork.
Outgenes.tsv, reactions.tsv, pathways.tsv, transporters.tsv, intermediate_metabolites.tsv, source_target_metabolites.tsv, currency_*.tsv, daa_*.tsv, excluded_pairs.tsv, summary.json, cytoscape/*.graphml

B

Structural check, stage diagrams and atlases

structure.py → stage_diagrams.py → tools/atlas, tools/report

A data-free check of each pruning stage (raw → inorganics → cofactors → pools → edits, plus an alternative where cofactors are removed everywhere). For every node it records degree, structural current with 150 random sources and 150 random targets, and pocket size (how many metabolites the node alone cuts off). The diagrams put every stage on one shared layout. The atlas and report builders embed these results in the HTML pages in docs/.

  • structure.stages() · _pruning_stages() · _carbon_stages()A CurrencyRules object per stage.
  • analyse_stage()Calls current_flow on random pairs; concentration() gives the top-1% share of current.

  • stage_diagrams.fruchterman_reingold()Force-directed layout written in numpy → .cyjs + Cytoscape style XML.

C

Carbon-skeleton channels (experimental)

python -m metaboenrich.atoms --out data/atom_pairs.json

Works out which substrate→product pairs in each reaction share carbon atoms, so current can follow carbon skeletons (glutamate→2-oxoglutarate in a transaminase, not glutamate→alanine). It uses KEGG's curated RCLASS pairs where KEGG has the reaction, and cleaned atom maps elsewhere. The output feeds step 4 through --atom-pairs. It is off by default; see decision D15.

Functions
  • load_smiles()Human-GEM's metabolites.tsv (pinned, hash-checked).
  • map_model(model, smiles)Atom-maps every reaction in batches of 8 (about 10 minutes on CPU; cached in atom_pairs_raw.json).
  • carbon_pairs(mapped_rxn, …)Counts carbons shared by each substrate and product, using atom-map numbers.
  • clean_pairs()Keeps a pair only if the substrate is the product's main carbon source, or the product is the substrate's main carbon destination.
  • kegg_pairs_for_model() · fetch_kegg_rclass_pairs() · combine_pairs()

D

Inborn-error benchmark

benchmarks/get_benchmark_data.py → python -m metaboenrich.benchmark

Asks whether the known defective enzyme ranks near the top. Data are plasma metabolomics z-scores from Thistlethwaite et al. 2020 and Miller et al. 2015. At group level, a metabolite is significant if the z-test on mean z gives BH q < 0.05 and |mean z| ≥ 1; at patient level, if |z| ≥ 2. The causal gene's rank among the 2,302 network genes is compared against a neighbour baseline.

Functions
  • get_benchmark_data.main()Downloads the CTD 1.3 R package from CRAN and exports its datasets with Rscript.
  • load_t2020() · load_miller() · group_daa() · patient_daa()
  • Ranker.run()load_daa → current_flow → node_table → reaction_table → gene_table, for raw and leave-one-out scoring.
  • best_rank()The best rank of any causal gene.
Packages
  • pandasz-score matrices and result tables.
  • numpyIts own bh(); medians.
  • math.erfc · subprocess · tarfilez → two-sided p; running R; unpacking the package.
  • R (Rscript) · CRANOnly to fetch the data; no R packages needed.

Blind predictions on published datasets

python benchmarks/published_predictions.py --out predictions/published_v1

Splits the lab's standardised master spreadsheet into analysis units, applies a significance rule fixed in advance, and runs the unchanged command-line tool on each unit. The answer key is never read, and the outputs are trimmed and committed before anyone looks at it.
